对内地用户比较实用的组合：电信用户主力看洛杉矶 DC6 和 DC9，回程都是 CN2 GIA 级别；移动用户可以试香港 CMI；联通用户有阿姆斯特丹 AS9929 和大阪软银两个方向。迁移全程在 KiwiVM 面板里自己操作，不需要提工单。

带宽有个容易被忽略的细节：套餐标注“高达 2.5Gbps”，但具体到每个机房会不一样，比如悉尼是 2.5Gbps，新泽西只有 1Gbps。对速度有要求的，迁移前先确认目标机房的端口规格。
